# BiteWiseApp

BiteWiseApp is a Windows Forms (WinForms) desktop application built using C# and Entity Framework. It is part of the BiteWise system, designed to help users track their dietary intake, monitor weight goals, and manage health profiles conveniently from their personal computer.

## Purpose
This desktop application allows users to:
- Register and log in securely.
- Log daily food and workout activities.
- Track personal health goals like weight, age, height, and daily caloric targets.
- View summaries of daily intake and progress toward goals.

## Technologies Used
- C#
- WinForms
- Entity Framework 6
- SQL Server (Remote)

## How to Run
1. Clone the repository to your local machine.
2. Open the solution (`BiteWiseApp.sln`) in Visual Studio.
3. Ensure your connection string in `App.config` points to your remote SQL Server.
4. Build the solution.
5. Run the application via `F5`.

> ⚠️ **Note**: The application requires access to a live SQL Server instance that contains the BiteWise database schema and seeded user data.

## Folder Structure
- `Forms/` – Contains all WinForms screens such as Login, Dashboard, Food Log, User Profile, etc.
- `Classes/` – Entity classes generated by Entity Framework for database interaction.
- `Resources/` – Includes static files like icons, images, etc.
